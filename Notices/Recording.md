Video snippets use ScreenRecorderLib 7.0.1 (MIT), by Sverre Kristoffer Skodje.
https://github.com/sskodje/ScreenRecorderLib

Recording uses Windows Media Foundation and requires the Microsoft Visual C++ x64 Runtime. Windows N/KN editions need the Media Feature Pack. The recording dependency is loaded only by Jago-Recorder.exe; notes and image capture remain independent.
