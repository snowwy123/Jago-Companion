# Jago Companion 0.7.3

Keep the little things close.

Quick notes, floating tasks, screenshots, video snippets and file previews in a lightweight offline companion. Use the notebook, keep a sticky beside your work or capture something without breaking your flow.

[Website](https://jagosuite.co.uk/) · [Downloads](https://github.com/snowwy123/Jago-Companion/releases/latest)

## Get started

Download **Jago-Companion-v0.7.3.zip**, right-click it and choose **Extract All**. Open **Jago-Companion.exe** from the extracted folder. Keep supporting files together. No installer is needed for the portable edition.

Windows requires 64-bit Windows and .NET Framework 4.8. PDF/Markdown previews use Microsoft Edge WebView2 Runtime.

Read **Documentation/Jago-Companion-Guide.pdf** for an illustrated introduction, tools and connected workflows. Save editable projects as well as finished exports.

## Tools

- Named notes with autosave, search, formatted reading, source editing and task views.
- Independent floating stickies with their own background, font, opacity, pinning and position.
- Region/window/display screenshots, PNG/JPEG preferences and annotations.
- Video snippets with optional sound, microphone and live drawing.
- Capture launcher, optional widget, email-signature designer and configurable shortcuts.
- Selectable offline text recognition in image captures.
- Optional Explorer Space previews for images/GIFs, audio/video, PDFs, Markdown and text; off by default.
- Video/audio preview Loop and one-click Replay; safer seeking.
- Screen colour picker with magnifier, HEX/RGB copy and twelve local recent swatches.
- Workscape tab/sidebar/floating modes, capture inbox connection and refined small-window controls.
