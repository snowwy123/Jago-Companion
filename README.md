# Jago Companion

Keep the little things close.

Write a quick note, keep a task list beside your work, or grab a screenshot or short video. Capture, annotate and find the original file again when you need it.

## Give it a try

Install with Jago Suite, or extract the portable download and open **Jago-Companion.exe**.

Open Companion to write a note or pin a sticky. For quick screenshots, pin Jago Capture to your taskbar.

[Find Jago Suite and downloads](https://jagosuite.co.uk/)
